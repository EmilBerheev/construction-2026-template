## Как запустить

```bash
uv sync                                     # зависимости и Python 3.14
uv run alembic upgrade head                 # схема базы (SQLite, файл app.db)
uv run uvicorn app.api.main:app --reload    # API на http://127.0.0.1:8000, документация /docs
uv run pytest                               # тесты
```
