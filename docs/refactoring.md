## Журнал рефакторинга

Не меньше 5 записей. Одна запись — один коммит с сообщением `refactor(область): …`, который
меняет код в `src/`. Хеш берите из `git log --oneline`. После записи хешей не делайте
`rebase` и `squash`: хеши изменятся, и автопроверка их не найдёт.
