# NNNN. Короткое название решения

Шаблон ADR (Architecture Decision Record, запись архитектурного решения) по Майклу Найгарду.
Скопируйте файл как `0001-kratkoe-nazvanie.md` и заполните. Этот файл автопроверка
не считает. Одно решение — одна запись. Принятые ADR не переписывают: если решение
поменялось, заводят новую запись, а у старой меняют статус на «Заменено NNNN».

## Статус

Одно из: Предложено, Принято, Отклонено, Заменено NNNN, Устарело. Добавьте дату ДД.ММ.ГГГГ.

## Контекст

Какая проблема или вынуждающая сила. Какие требования из docs/requirements.md (US, NFR)
на это влияют. Какие варианты рассматривались: минимум два, с плюсами и минусами.
