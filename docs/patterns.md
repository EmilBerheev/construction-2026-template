## Паттерны GoF

Не меньше трёх паттернов, по одному из каждой группы: порождающий, структурный,
поведенческий. Автопроверка разбирает таблицу: в колонке «Файл» путь от корня репозитория
(`src/app/...py`), в колонке «Класс» имя класса из этого файла (можно несколько через
запятую). Каждый класс из таблицы должен встречаться в тестах.
